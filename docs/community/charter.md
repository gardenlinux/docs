# Charter

## Purpose

Garden Linux develops a minimal, immutable, API-driven operating system layer for
automated, Kubernetes-centric platforms. The project exists to provide a
purpose-built, fully open source Linux distribution for cloud-native workloads
and to document how it is built, operated, and extended.

## Scope

The project covers the operating system itself, its build and test tooling, the
supporting libraries and services that make releases usable, and the
documentation that describes all of the above.

The project is **not** a general-purpose operating system. It is optimized for
the use cases described in the [Introduction](/introduction/) and the
[Use Cases](/explanation/use-cases) page.

## Roles and responsibilities

### Contributors

Anyone who proposes changes, reports issues, writes documentation, or participates
in reviews. Contributors are expected to follow the project's Code of Conduct and
contribution guidelines.

### Maintainers

Maintainers review and merge contributions, set technical direction, and
represent the project. The current maintainer roster is maintained on the
[Members](./members.md) page.

### Security Team

The Security Team coordinates the responsible handling of security
vulnerabilities. The process is described in the
[Security Response Process](/contributing/security).

### Release Managers

Release Managers build, publish, and announce Garden Linux releases. Their
responsibilities are described in the release documentation.
