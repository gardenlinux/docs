## Role descriptions

- **Maintainers** review and merge contributions, set technical direction, and
  represent the project.
- **Security Team** coordinates the private and public handling of security
  vulnerabilities.
- **Release Managers** build, publish, and announce Garden Linux releases.
- **Documentation Lead** coordinates the documentation hub and reviews
  documentation changes.
- **Contributors** propose changes, report issues, write documentation, and
  participate in reviews.

See the [Charter](./charter.md) for the responsibilities attached to each role.

## Becoming a member

There is no formal membership fee or application process. The most common path is:

1. Start by contributing to an area that interests you, such as documentation,
   tests, packaging, or platform support.
2. Participate in reviews and discussions on the
   [Community Outreach](./outreach.md) channels.
3. Ask a maintainer about taking on a named role once you have a track record of
   contributions.
